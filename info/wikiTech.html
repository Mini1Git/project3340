Site Technology Guide

The core Technology

Grillow was built using:

HTML5 - the structural backbone of our website, using tags to make sure the site is organized and accessible.

CSS - used for the visual design. We used external stylesheets to keep the code organized, and seperated stylesheets into categories for different pages.

Javascript - powers the interactivity of the side. This handles things such as hamburger menu toggles, theme switcher , and form validation, before the data is sent to the server.

PHP - Our server-side language was PHP. It takes requests from the user, talks to the database, and brings back dynamic content for users to see on the website.

MySQL - Our relational database management system. we used MySQL to store our unique records of food items, user profiles, restaurant vendors, etc.

Dynamic and Static pages

Grillow is made up of two types of pages. Static pages like "About Us", where the content does not change accross users. These are written with just HTML and have fast loading speed. Dynamic pages like "Browse", "Cart", "Orders", etc. change based on the user who is logged in, and what is in the database. These are generated in real time by PHP.

Other Resources

We used FontAwesome, an icon library for navigation icons and Wiki icons, that can easily be modified like text to match our themes and layouts.

Responsiveness

Using Flexbox, Grid, and Media Queries, the site automatically adjusts for three screen sizes: Desktop, Tablet, and Mobile. No matter the screen size the experience remains consistent, and our site looks nicely styled and organized.

Software Repository

All of Grillow files that make up our website, were documented in GitHub. This lets us collaborate as a team on development, and keep track of documentation and version history, update history, etc.
