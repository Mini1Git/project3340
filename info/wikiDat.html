Site Database Guide

Introduction to the Dynamic system

Unlike a static website where you have to change code to change a price, Grillow is fully dynamic. This means the frontend (what customers see) is a "window" into our MySQL Database. When you update a record in the database via the Admin Portal, the website updates instantly across all devices

Menu Management

Restaurant owners can manage the products on their menu without ever touching a line of code. Our PHP backend handles the communication between our website, and the products table in the database.

Order management and fulfillment

Every time a customer clicks "Checkout," a new order is generated in the database's orders table with a unique Order ID. An order can have a status of "0" for not completed yet, and "1" for fulfilled.

Administrators

User Moderation: Admins can view all user records. If a user violates our terms of service, their account can be disabled, preventing them from logging into the PHP session.

Initial Catalog Setup

The initial catalog setup was performed via a batch SQL script to ensure the site was launched with a full variety of 20+ restaurants each with 10+ products and descriptions.
